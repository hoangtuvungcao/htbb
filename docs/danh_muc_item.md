# Danh mục vật phẩm (data_item)

File này được **sinh ra**, đừng sửa tay.
  Nguồn  : sql/gamedb7_clean.sql, bảng `data_item`
  Sinh lại: java -cp "build/classes;lib/NQSH_5h.jar;lib/mysql-connector-java-5.1.49.jar" SinhDanhMucItem

Mục đích: tra nhanh **id ↔ tên vật phẩm** khi đọc/viết code (giftcode, shop,
chế tạo, danh sách vật phẩm sự kiện...) thay vì tự query DB hay đoán từ magic
number rải rác trong `Item.java`/`ModelWearing.java`. `type` là cột thô từ DB
(xem cách dùng trong `Item.java` nếu cần biết ý nghĩa từng giá trị — không lặp
lại ở đây để tránh lệch khi type có thêm giá trị mới). `icon` = cột `xstart`
(id ảnh, xem `map/icon/<icon>.png`); dải 800-806 BỊ CHẶN (xem `map/other/`,
và mục 2 trong ghi chú icon của dự án) — đừng gán vật phẩm mới vào dải đó.

test/KiemDanhMucItem.java đối chiếu số lượng + vài id mốc với chính file SQL.
